YamlWhy
Your country code NO is not the string "NO" in every YAML parser.
Open the app
In YAML 1.1, NO is the boolean false. In 1.2 core it is a string. 010 is 8 in 1.1 and 10 in 1.2. 1:30 is the integer 90 in 1.1 (base 60). 2001-12-14 is a date in 1.1 and a string in 1.2 core.

What it does

  • Shows the type of each key: value line under YAML 1.1 and 1.2 core, side by side.
  • Flags lines that change type between versions.
  • Runs in your browser. Nothing is uploaded.

How far to trust it

  • The engine is checked against the yaml package, js-yaml and PyYAML on about 1500 random scalars. 1.2 matches both libraries exactly. 1.1 matches the spec pages, and the README lists where the libraries differ from them.
