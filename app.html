One line per entry, written as key: value. See the type each parser family gives the plain value.
LineYAML 1.2 coreYAML 1.1
1.1 follows the yaml.org/type pages. 1.2 follows the core schema. Real parsers deviate in corners (PyYAML has no y/n booleans; the yaml package accepts 08 and 1e3 in 1.1 mode). Details in the README. Quoted values are always strings. Handles single-line plain scalars only, not full YAML.
